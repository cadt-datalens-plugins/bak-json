# bak-json — CaDt-DataLens 插件

把 `.bak` 文件按 JSON 解析查看：树视图编辑、格式化（Ctrl+Alt+L）、保存都会走 JSON；内容不是合法 JSON 时自动退回纯文本视图。

附带一个演示命令（工具菜单 →「统计当前文件字符数」）和一个演示主题（主题菜单 →「演示主题」）。

## 安装

1. 在本页选择 **代码 → 克隆/下载 → 下载 ZIP**（ZIP 内根目录即 `plugin.json`，无需解压改名）。
2. 打开 CaDt-DataLens → 设置 → 插件 → **导入插件(.zip)…**，选择刚下载的 ZIP。
3. 列表中确认插件已启用，重新打开 `.bak` 文件即可生效。

也可以「添加插件…」直接选择克隆到本地的本目录文件夹。

## 依赖

- CaDt-DataLens v1.0.0 及以上（2026-11-08 之后的构建）
- 无需其他运行环境

## 卸载

设置 → 插件 → 本插件行 → 删除（两段确认）。
